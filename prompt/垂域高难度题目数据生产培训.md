# 垂域高难度题目数据生产培训

## 核心目标

> "基于行业背景，布置复杂任务。"

### 题目核心要求

1. **事实准确性**：题目符合真实生活场景，不可直接使用大模型批量生产
2. **专业深度**：在真实业务领域中可能出现，体现专业深度
3. **时效性**：题目与时俱进
4. **复杂度**：解决题目需要复杂推理、多附件处理；人类专家处理需至少 **8小时** 以上
5. **隐私性**：题目中涉及企业、机构相关信息，需统一使用"某公司""某机构"等泛称替代，禁止出现具体机构、企业名称。

## 三、题目制定规则

### 3.1 同质化要求

**核心原则**：必须由专家亲自设计，严禁使用大模型批量生产！违反将导致数据作废。

同一批次中，30%以上题目仅替换关键词视为同质化，须全部重写。

### 3.2 同质化检查标准

| 检查项 | 不通过标准 | 处理方式 |
|--------|-----------|----------|
| 题目相似度 | 同批次 >= 30% 的题目仅替换关键词 | 拒收，要求重写 |
| 题目长度 | 同批次 80% 以上长度差异 < 10% | 警告，要求调整 |
| 题目句式 | 同批次 >= 50% 使用相同句式模板 | 警告，要求多样化 |
| 题目结构 | 同批次 >= 50% 的题目结构相同 | 拒收，要求重写 |

### 3.3 正向要求

- 同一场景的题目需在措辞、句式、详略程度上有差异
- 尽可能符合正常人类的生活需求和语言表达

## 四、出题方法论

### 4.1 事实准确性

1. **分清"可验证的事实"和"纯观点"**：比如"地球是圆的"是可验证事实，"这个电影最好看"是个人主张，出题时要把两者划清，不能混为一谈
2. **设计两类题目**：
   - 有唯一标准答案、卡死条件的题（如数学公式计算、法规条文）
   - 没有唯一答案、需要权衡的题（如方案选型、创意设计）
   - 出题要能灵活用这两种约束，覆盖不同考察场景
3. **所有信息都能溯源**：题目里用到的事实、数据，都要有可查的来源链接，不能凭空造内容

### 4.2 专业深度

1. **考多步推导和反事实分析**：不是考"背答案"，而是考"怎么推出来的"，甚至要考"如果条件变了，结果会怎么样"，倒逼大模型真懂逻辑
2. **考多方案对比和权衡（tradeoff）**：出那种"没有完美方案，只能选最合适"的题，比如A方案省钱但慢，B方案快但贵，让大模型分析利弊、做取舍，考察专业判断力
3. **考隐含假设和边界条件**：挖那些"默认成立但没说出口"的前提，比如"这个算法在XX场景下才有效"，出题要能测出大模型有没有意识到这些边界，会不会踩坑
4. **题目具备行业深度**：完全符合白领的真实工作场景，题目中一定要包括复杂的信息分析任务（大量数据分析对比），或者重大决策建议，或者对于实效性/事实准确性的测试

### 4.3 时效性

1. **懂不同知识的更新节奏**：比如科技、政策类知识更新快，基础理论类知识更新慢，出题要贴合这个节奏，不能用10年前的旧标准考现在的内容
2. **给题目加"时间锚点"**：出题时明确标注"截至XX年XX月""按XX年最新标准"，让大模型知道该用哪个时间点的知识，避免歧义
3. **设计"过期陷阱"题**：故意用已经过时的知识当干扰项，比如用旧版法规、淘汰的技术做错误选项，检验大模型有没有及时更新知识，会不会踩"用老经验解决新问题"的坑

## 五、附件规定及输出要求

### 5.1 附件数量与关联要求

- 题目制订时上传8个相关附件（**固定8个**），附件必须和题目强相关，不可以脱离题目独立存在
- **每道题用到的附件数量为8个。**
- 题目建立在附件基础上，同时要有复杂的推理逻辑链路（即题目设定不可以过于直接），要有多个附件的调用
- 在题目中需要明确提到附件，可以大概介绍下附件的内容，也可以说让模型根据附件去执行任务。题目中要表述清楚附件的作用，题目中关于附件的表述要和上传的附件文件名对应起来
- 报价和附件数以及问题的复杂性正相关
- **每个附件最多用于两条数据**

### 5.2 附件格式要求

- 数据格式要求以文字类/结构化数据为主：
  - 项目以生产长难Excel数据任务为主，优先制作包含多工作表、多元素复合公式的Excel数据内容，同时减少其他类型数据的生产占比。生产支持三种合规方式，均可正常使用：一是原始附件不限文件格式，最终产出长难Excel产物（多工作表、含公式、数据透视表等）；二是仅以Excel作为原始附件，最终同样产出长难Excel产物（多工作表、含公式、数据透视表等）；三是8个附件全为PDF时，产物必须包含长难Excel（多工作表、含公式、数据透视表等）；附件包含文档（Word、TXT、飞书文档、Markdown等文本类格式）或网页（HTML格式）时，产物可不包含Excel。
  - 文本类：Word/飞书文档/TXT
  - 图表类：Excel/飞书表格/多维表格
  - 静态网页类：需为 **.html** 格式，不可以以链接形式存在，html 最多 2 个
  - PDF
- **PDF占比要在20%以上****
- 其他格式分布趋于平均即可
- 附件大小尽量在 **10M-500M** 之间
- 鼓励文件中包含图片，比如图文交织的PDF

### 5.3 输出产物要求（强制体现在题目中）

不要把产物固定写成永远三件套，必须根据题目方向灵活变化
可以要求的产物类型：
- 复杂表格
- 复杂 visualization/demo
- 复杂商业/经营管理图表（甘特图、鱼骨图、复杂交互式统计图等）
- 知识拓扑图等

> 示例：输出一份Word版本主报告，输出Excel格式的四项动作优先级矩阵
